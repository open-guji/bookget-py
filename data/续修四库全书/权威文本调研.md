#### 描述格式（每册）

```
《續修四庫全書》第NNNN冊，內含：
  《书名X卷》，部 子类，朝代+作者+角色，影印XX藏XX本；
  《书名Y卷》，部 子类，朝代+作者+角色，影印XX藏XX本；
  ……
```

例（第 0001 册）：
> 《續修四庫全書》第0001冊，內含：《周易新講義十卷》，經部 易，宋龔原撰，影印復旦大學圖書館藏日本文化五年活字印佚存叢書本；《周易正義十四卷》，經部 易，唐孔穎達撰，影印國家圖書館藏宋刻遞修本；……

#### 数据字段

每条书目可解析出：
- `sec_part`：经/史/子/集
- `ce`：册次
- `sub_class`：子类（易类/书类/...）—— **史部/集部多数无细分子类**（仅标"史部"、"集部"）
- `title`：主书名
- `juan_count`：卷数
- `dynasty`：朝代
- `author`：第一作者
- `role`：撰/輯/纂/注/疏/編 等
- `holding`：藏馆名（如"国家图书馆"、"复旦大学图书馆"）
- `edition_raw`：底本完整描述

## 关键经验

1. **31hy ID 段问题**：约 909 条历史 Work 的 ID 编码 type=Reserved1，BookIndexManager 默认 reindex 会失败。脚本必须传 `type_val=BookIndexType.Work` 强制指定
2. **作者解析 BUG**：续修四库 Commons 描述里 `劉定之撰` 因为 `定` 在 ROLE 列表里（来自"後定"），被误拆成 `劉/定/之撰`。解决：移除 ROLE 中容易误伤的单字 `定/訂/集`，只保留多字组合
3. **「題後魏」DYN 漏字**：DYN 列表里只有「北魏」没有「後魏」，需补
4. **同名异书的处理**：作者校验失败时**不**强行匹配现有 Work，而是新建并在 ai_note 标注「索引中尚有同名异书：xxx」
5. **同名异书占比**：6095 条目录中 4425 条需新建（72.6%），其中很多是同书别本/异作者的情况
6. **缓存失效**：subprocess + flush=True + buffer 问题导致后台日志看不见，必须 `python3 -u` + `flush=True`
