### 三种著录格式（原文档系拼接而成）

```
A  經部/史部前段：`類`标题 + `第 N 冊`分组，其下 `書名 卷數 朝代作者`     ← 无底本信息
B  史部后段/子部/集部前段：`書名卷數 (朝代)作者撰 X部第 N 冊 影印底本`
C  集部后段：`X部第 N 冊：書名卷數(朝代)作者撰 影印底本`
```

冊 896–901、1160、1308、1320 等处 A 与 B/C 重叠著录同书，脚本按书名+部去重并合并冊次区间。

### 踩过的坑

1. **CJK 相容表意文字**：PDF 中「易」是 U+F9E0、「類」是 U+F9D0（Compatibility Ideographs），而非常用码位 U+6613/U+985E。所有正则静默失配，`類` 字段全空。解法：读入即 `unicodedata.normalize("NFKC", raw)`。
2. **類 标题不重置**：B/C 段落原文不带 `類` 标题，沿用格式 A 遗留值会把 3185 条全标成「金石類」。解法：B/C 条目 `類` 置空。
3. **多冊分载 ≠ 多种**：格式 A 每冊重列书名，《欽定大清會典事例》出现 17 次。须按书名合并、取冊次区间，否则虚增约 500 条。
