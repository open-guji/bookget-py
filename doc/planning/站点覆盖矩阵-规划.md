## E. 统计

- bookget 真实站点：约 **50** + 3 通用模式
- bookget-py 现有：约 **37** 站点（含 keio/ryukoku/toyobunko/tnm）
- ✅ **Zoomify 瓦片拼接引擎已落地**（`bookget/downloaders/tiles.py`，TNM 已用、live 验证）；DeepZoom 变体（`tiles/infos.json` 省级方志）可在此基础上接
  - Phase 3 IIIF（live 验证）：bodleian/vatican/cambridge_cudl/berlin_sbb/kokusho/smithsonian/emuseum/khirin
  - Phase 4（用户给真实 URL，chrome-mcp 抓接口 + live 验证）：hkust（HKUST）、taiwan_ebook（台湾华文电子书库 PDF）
  - Phase 3 非纯 IIIF（live 验证）：loc（LOC JSON API）、onb（迁 IIIF v3，base_iiif 已补 v3 解析）
  - hku（暂停，站点访不通）
- **缺口**：约 **19** bookget 站点（B 节）+ 通用 DeepZoom/批量模式
- ⚠️ 反爬/受限：CUHK 有 WAF（沙箱全 403，归反爬阶段）；大陆站多 geo 限制，建议可达环境（GCP dev-vm / 本机）验证
- 💡 NCL 系（taiwanebook）TLS 证书缺 SKI，Python 3.13+ strict 验证会拒，适配器放宽 `VERIFY_X509_STRICT`
- **增量**：调研补充约 **7 个全文源** + **2 个免费 IIIF**（C 节）
- 目标终态：站点数 ≥ bookget，且文本/元数据/搜索全面超越（bookget 三者皆无）
